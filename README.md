# AQRM

Numerical resources for studying the asymmetric quantum Rabi model (AQRM) with a Brownian-oscillator environment. This repository contains the least-square fitting procedure used to obtain the environmental parameters, bosonic-cutoff convergence data for the effective Hermitian Hamiltonian, spectra for comparing the effective model with the complete Fokker–Planck quantum master equation (FP-QME), and the three figures from the original manuscript with their captions.

## Repository contents

| Directory | Contents | Purpose |
| --- | --- | --- |
| [Least-square fitting](Least-square%20fitting/) | Fitting notebook, supporting `deom` package, and instructions | Fit the Brownian-oscillator correlation function and obtain the parameters used in the subsequent calculations. |
| [N_cut_convergence](N_cut_convergence/) | Effective-Hamiltonian energy tables, cutoff comparisons, and instructions | Check the convergence of the low-lying eigenenergies with respect to the bosonic Fock cutoff. |
| [Liouvillian-spectrum](Liouvillian-spectrum/) | Spectral datasets and instructions | Compare the complete FP-QME spectrum with the commutator spectrum generated by the effective Hermitian AQRM. |
| [Original_figures](Original_figures/) | Three manuscript figures with their captions, exported as 600 dpi PNG images | Provide a reference for comparing level crossings and avoided crossings with the symmetry-resolved spectra. |

See the README in each directory for its detailed parameters, file descriptions, and execution or data-reading instructions.

## 1. Least-square fitting

The Brownian-oscillator response function is

$$
\chi(\omega)=\frac{\Omega_0}{\Omega_0^2-\omega^2-i\zeta_0\omega}.
$$

The corresponding correlation function is approximated by two exponential terms using least-square fitting:

$$
C_{\mathrm{fit}}(t)=\eta_+e^{-\gamma_+t}+\eta_-e^{-\gamma_-t}.
$$

The notebook reports the fitted coefficients, derived effective parameters, fitting errors, and fit-quality measures. Time-domain and frequency-domain plots show the comparison with the original correlation function.

The derived parameters include $\bar\Omega$, $\bar\zeta$, $\delta_0$, $\delta_1$, and $\delta_2$. The effective oscillator frequency and coupling are

$$
\Omega_{\mathrm{eff}}=\sqrt{\bar\Omega^2-\bar\zeta^2/4},
\qquad
g_{\mathrm{eff}}=g\left(1+\frac{\delta_2}{2}\right)
\sqrt{\frac{\bar\Omega}{\Omega_{\mathrm{eff}}}}.
$$

Keep the bundled `deom/` package beside the fitting notebook, including `__init__.py`, `deom.py`, and the required `spectrum/` source files. These files support the spectral decomposition used to construct the original correlation function. Preserve the lowercase package name and its directory structure so that `from deom import decompose_spe` works on Linux.

The fitting notebook displays its numerical results and figures directly; it does not automatically save them to disk.

## 2. Bosonic-cutoff convergence

The `N_cut_convergence/` directory checks the lowest 20 eigenenergies of the effective Hermitian Hamiltonian $H_H$ as the bosonic cutoff is increased. The reported test uses $g=4.5$ and cutoffs $N=60,80,100,120,140,160$.

| File | Description |
| --- | --- |
| `HH_levels_vs_N.csv` | Lowest 20 eigenenergies for each cutoff. |
| `HH_N100_convergence_check.csv` | Absolute energy differences between $N=100$ and the larger reference cutoffs. |

Here, $N$ is the number of oscillator Fock states retained, $n=0,\ldots,N-1$. With a two-level system, the Hilbert-space dimension is $D=2N$.

The comparison between $N=100$ and $N=120$ gives maximum absolute differences of approximately $1.176\times10^{-12}$ for the lowest ten levels and $4.961\times10^{-7}$ for the lowest 20 levels at the tested parameter point. These results establish the convergence of the effective-Hamiltonian levels considered. Convergence of the full Liouvillian spectrum must be assessed separately.

## 3. Liouvillian spectra

The `Liouvillian-spectrum/` directory compares two generators at the same fixed parameter point:

| Dataset | Generator | Interpretation |
| --- | --- | --- |
| Full FP-QME | The complete dissipative generator $\mathcal L$ | Complex modes of the density-matrix evolution, including the environmental contributions. |
| Effective Hermitian AQRM | $\mathcal L_{\mathrm{eff}}\rho=-i[H_{\mathrm{eff}},\rho]$ | Energy differences of the effective Hermitian Hamiltonian. |

For $N=100$, the Hilbert-space dimension is $200$ and the Liouville-space dimension is $40000$. The full calculation computes all 40,000 eigenvalues of the finite FP-QME generator before selecting the exported subset.

For the effective model, all 200 Hamiltonian eigenvalues $E_i$ are calculated and all 40,000 ordered differences $E_i-E_j$ are formed. This gives the complete spectrum of its commutator generator, including zero and repeated differences.

### Spectral convention

For

$$
\frac{d\rho}{dt}=\mathcal L\rho,
$$

let $\lambda$ be an eigenvalue of $\mathcal L$. The exported data use

$$
\mathcal E=i\lambda,
\qquad
\operatorname{Re}(\mathcal E)=-\operatorname{Im}(\lambda),
\qquad
\operatorname{Im}(\mathcal E)=\operatorname{Re}(\lambda).
$$

Thus `Re_E` describes the oscillatory frequency in this convention, while `Im_E` gives the modal growth or decay rate. A negative `Im_E` corresponds to decay. For the effective commutator generator, $\mathcal E_{ij}=E_i-E_j$ is real.

The spectral CSV files contain the first 10,000 entries satisfying `Re_E > 0.0`, sorted by increasing `Re_E`. Both real and imaginary parts are retained, and repeated eigenvalues are kept. The positive-real-part selection applies to $\mathcal E$, rather than to $\lambda$.

The selected CSV files contain subsets of the spectra. Where provided, `all_E_complex128.npy` and `all_lambda_complex128.npy` retain the complete numerical spectra, and `run_metadata.json` records the parameters and diagnostics.

Equal row numbers in independently sorted full and effective datasets do not identify corresponding modes. The hidden symmetry of the effective Hermitian Hamiltonian does not by itself establish a symmetry of the complete dissipative generator.

## 4. Figures from the original manuscript

The [Original_figures/](Original_figures/) directory contains the three figures from the original manuscript, each including its original caption. These figures are provided as a reference for comparing level crossings and avoided crossings with the symmetry-resolved spectra.

| File | Contents |

## Requirements and use

The numerical work uses Python 3 with NumPy and SciPy. The fitting notebook additionally uses SymPy, Matplotlib, Pandas, and the bundled `deom` package. A Jupyter-compatible environment is needed to run the notebooks. Python 3.7.0 was used in the reported calculations.

1. Run the least-square fitting notebook from the beginning, keeping its supporting package in the required location.
2. Use the fitted parameter set consistently when examining the convergence and spectral results.
3. Consult the convergence tables for the effective-Hamiltonian levels of interest.
4. Read the full and effective spectral datasets using the convention above and the column definitions in their directory README.

CSV files can be opened in Python, Origin, or spreadsheet software. Full-spectrum NumPy files can be loaded with `numpy.load`. Large full Liouvillian calculations require sufficient memory and computation time; notebook and cluster execution details are documented with the corresponding calculation files.
